# Security policy

This policy applies to every eurus-labs repository that has no `SECURITY.md` of its own.

## Reporting a vulnerability

Do not open a public issue, discussion or pull request for a vulnerability.

Report it privately: open the repository's **Security** tab and choose **Report a vulnerability**. This
creates a private advisory that only you and the maintainers can see.

Please include:

- the affected repository and version (release tag, extension version or commit);
- what an attacker can do, and under which conditions;
- the steps or a minimal proof of concept to reproduce it.

The maintainers will acknowledge the report in the advisory, keep you updated there, and credit you
when the fix is published unless you ask not to be.

## Supported versions

Security fixes go into the latest release of each project. Upgrade to it to receive them.
