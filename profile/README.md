# eurus-labs

Tools for developers: Git workflows across repositories, agent skills for AI coding assistants, and
desktop utilities.

| Project | What it is |
| ------- | ---------- |
| [Repository-Manager](https://github.com/eurus-labs/Repository-Manager) | A VS Code extension for Git workflows across a parent repository and its submodules, from one dashboard, with Copilot reviews. |
| [Skills](https://github.com/eurus-labs/Skills) | Agent Skills for GitHub Copilot and other skills-compatible agents, grouped into installable plugins. |
| [SimpleExplorer](https://github.com/eurus-labs/SimpleExplorer) | A fast, multi-pane file explorer for Windows, built with Neutralinojs. |

Want to help? Read [how to contribute](https://github.com/eurus-labs/.github/blob/main/CONTRIBUTING.md).
To report a vulnerability, follow the [security policy](https://github.com/eurus-labs/.github/blob/main/SECURITY.md).
